# CataloGo — Catálogo Comercial Modular

Proposta v0.1: produto-base replicável para pequenos estabelecimentos, com identidade comercial configurável. O consumidor consulta produtos, monta o carrinho e encaminha uma solicitação de pedido por WhatsApp. O comerciante gerencia seus dados e catálogo em painel protegido.

## Escopo
- Uma instalação independente por estabelecimento.
- Sem pagamento online, cadastro de consumidores ou multi-tenant no MVP.
- Estoque quantitativo, promoções, delivery, agendamento, relatórios e pagamentos são módulos futuros, não requisitos atuais.
- Monetização possível: implantação, manutenção recorrente e funcionalidades adicionais. Preços e viabilidade ainda não validados.

## Critério comercial
Replicar para um segundo estabelecimento fictício alterando dados e configuração visual, sem reescrever a lógica.

## Roteiro sugerido para exercício curto
1. Fundação visual, dados fictícios, catálogo navegável.
2. Carrinho, persistência local e checkout WhatsApp.
3. Administração, autenticação, persistência remota e publicação, conforme tempo disponível.

O protótipo de aula não equivale ao MVP comercial validado. Nenhum código implementado aqui.
