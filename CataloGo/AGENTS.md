# Diretrizes para desenvolvimento assistido por IA

- Trabalhar incrementalmente, somente na etapa solicitada.
- Preservar funcionalidades existentes e validadas.
- Separar interface, lógica de negócio, persistência e integrações.
- Centralizar configurações específicas do estabelecimento.
- Priorizar componentes reutilizáveis e baixo acoplamento.
- Evitar duplicação, dependências desnecessárias e funcionalidades futuras antecipadas.
- Não expor credenciais no frontend ou repositório; usar dados fictícios nos exemplos.
- Não alterar contratos sem avaliar impacto; solicitar aprovação para mudanças arquiteturais significativas.
- Validar cada etapa antes de prosseguir; documentar alterações, decisões, limitações e pendências.
- Não declarar testes realizados se não foram executados.
- Não publicar dados pessoais, contatos reais, chaves ou informações de clientes.
