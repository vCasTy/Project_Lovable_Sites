# Project Lovable Sites

Repositório de apoio ao curso presencial de criação de sites com Lovable (24 a 26/11/2026, 18h30–20h30). Serve como ponte para consultar e copiar contexto, checklists e prompts durante as aulas, não como repositório de código de uma aplicação já implementada.

## Projetos

### CataloGo — Catálogo Comercial Modular (proposta v0.1)

Produto-base replicável para pequenos negócios: catálogo responsivo, carrinho, encaminhamento de pedidos ao WhatsApp e painel administrativo. Uma instalação independente por estabelecimento inicialmente; identidade visual e dados configuráveis sem reescrever a lógica.

## Como usar na aula

Leia o conceito, consulte o checklist e copie apenas o prompt da etapa atual para o Lovable. Ajuste as instruções à metodologia do professor e valide o resultado antes de avançar. O plano de seis horas é orientativo, não uma promessa de entrega.
